# SOC L1 Alert Reporting

## Overview

This room covers the fundamentals of alert reporting, escalation, and communication in a Security Operations Center (SOC). It focuses on how SOC Level 1 analysts document suspicious activity, communicate findings, and escalate alerts that require further investigation.

## Learning Objectives

- Understand the importance of alert reporting and escalation
- Learn how to write clear and structured alert reports
- Apply the Five Ws approach to incident documentation
- Understand when and how to escalate alerts to Level 2 analysts
- Learn communication best practices during security incidents
- Practice alert handling through a simulated SOC dashboard

## Tasks Completed

### Task 1: Introduction

Reviewed the responsibilities of SOC L1 analysts and the importance of reporting, escalation, and communication during alert investigations.

### Task 2: Alert Funnel

Learned how alerts move through the SOC workflow, from initial triage by L1 analysts to escalation to L2 analysts and, when necessary, further incident response.

Key concepts:
- Alert reporting
- Alert escalation
- Communication between security teams

### Task 3: Reporting Guide

Studied the purpose of alert reports and how proper documentation supports further investigation, preserves findings, and improves analytical skills.

Practiced using the Five Ws approach:

- Who: The user or account involved
- What: The suspicious activity or event
- When: The time the activity occurred
- Where: The affected device, IP address, or website
- Why: The reasoning behind the alert verdict

### Task 4: Escalation Guide

Learned when alerts should be escalated to L2 analysts, particularly when an alert indicates a potential major attack, requires remediation, or needs additional expertise.

Practiced the escalation workflow:
1. Set the alert status to In Progress.
2. Investigate the alert and document the findings.
3. Assign an appropriate verdict, such as True Positive or False Positive.
4. Reassign the alert to the designated L2 analyst when escalation is required.

### Task 5: SOC Communication

Reviewed communication procedures for critical security situations, including unavailable senior analysts, potentially compromised communication accounts, alert spikes, missed malicious activity, and SIEM logging issues.

Key takeaways:
- Follow the established escalation chain during critical incidents.
- Use alternative communication channels when an account may be compromised.
- Inform senior analysts when alert volumes become overwhelming.
- Report suspected misclassifications immediately.
- Escalate logging and investigation obstacles instead of ignoring alerts.

### Task 6: Conclusion

Reviewed the importance of reporting, escalation, and communication in ensuring that security alerts are investigated and handled effectively.

## Key Takeaways

- Clear reports help L2 analysts understand the investigation without repeating the initial analysis.
- The Five Ws provide a consistent structure for documenting security events.
- Proper escalation ensures that high-risk alerts receive appropriate attention.
- Effective communication supports coordination between SOC analysts and other departments.
- Accurate documentation and evidence-based verdicts are essential for incident handling.
